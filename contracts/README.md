# Контракты, версия 1

models.py содержит структуры Pydantic, общие для бота и сервиса.
Все входы проверяются до обращения к модели. Лишние поля отклоняются.
Размеры — миллиметры; неуказанные значения — null.

Brief — полный актуальный набор параметров, не частичная правка.
DialogueResult — описание, ответ пользователю и нерешённые вопросы.
SketchRequest — проект, версия, request_id, описание, референсы.
SketchResponse — тот же проект и версия, PNG, использованная модель.

Файлы передаются в base64, а не как пути к локальной базе другого процесса.
При изменении несовместимого формата увеличивается contract_version.
